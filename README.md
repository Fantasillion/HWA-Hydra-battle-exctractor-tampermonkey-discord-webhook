# HWA-Hydra-battle-exctractor-tampermonkey-discord-webhook
Extract hydra battle info at export it manually via text or via webhook to discord


Instructions:
1. Install TamperMonkey
2. Copy the contents of TamperMonkey script in to a new script.
3. If you want to webhook in to a Discord server, upload these emojis to your discord server
4. Select these 5 hydra images in the script window
5. If you use Discord, copy the webhook url from the Discord channel you want to post data in and paste in the script window
6. Go to Guild -> Elemental Cradle -> Castle Ruins -> Defeated or Select any Hydra -> Journal
7. Check that data gets populated and that date is correct.
8. Send English to Discord/Send Russian to Discord/Manually copy and paste where ever you want
