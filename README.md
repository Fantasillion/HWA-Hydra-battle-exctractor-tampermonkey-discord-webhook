# HWA-Hydra-battle-exctractor-tampermonkey-discord-webhook
Extract hydra battle info at export it manually via text or via webhook to discord


Instructions:
1. Install TamperMonkey
2. Copy the contents of TamperMonkey script in to a new script.
3. ~If you want to webhook in to a Discord server, go the a text channel type \ and drag and drop these files one at a time and copy the upload these emojis to your discord server hydra_common.png hydra_common.png~ 
4. Download and select these 5 hydra images from the repository in the script window: common.png, elder.png, ancient, dreadful.png, legendary.png  
5. If you use Discord, copy the webhook url from the Discord channel you want to post data in and paste in the script window
6. Go to Guild -> Elemental Cradle -> Castle Ruins -> Either "Defeated" or "Select" any Hydra -> Journal and press the left and right arrow buttons until all 5 hydras have been sync'ed
7. Check that data gets populated and that the date is correct.
8. Send English to Discord/Send Russian to Discord/Manually copy and paste where ever you want
